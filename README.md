# Бот учёта клиентов

Телеграм-бот для сотрудников: каждый добавляет клиентов по их @username, бот не
даёт добавить одного клиента дважды и ведёт персональный счётчик.

## Возможности

- Доступ только у сотрудников, чьи Telegram ID перечислены в `EMPLOYEE_IDS`.
  Остальным бот отвечает отказом и показывает их ID (его можно передать
  администратору), попытка пишется в лог.
- Сотрудник определяется по своему Telegram ID (ничего регистрировать не нужно).
- Отправленный боту @username = клиент: он добавляется и закрепляется за
  сотрудником. Принимается `@ivan_petrov`, `ivan_petrov` или `t.me/ivan_petrov`.
- Повторный клиент не добавляется: бот сообщает, кто его уже внёс.
  Регистр не важен — `@Ivan` и `@ivan` считаются одним клиентом.
- `/stats` — свой счётчик, список своих клиентов и общая статистика: сколько
  клиентов добавил каждый сотрудник (по убыванию, свою строку видно как «вы»).
- `/all` — все клиенты в базе, видно всем сотрудникам.
- Защита от дублей на уровне БД: `username TEXT PRIMARY KEY COLLATE NOCASE`
  в SQLite — вставка дубля отклоняется самой базой, без предварительных проверок.

## Установка

```
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```
BOT_TOKEN=123456:ваш_токен
EMPLOYEE_IDS=111111111,222222222
```

`EMPLOYEE_IDS` — Telegram ID сотрудников через запятую. Без этой переменной бот
не запустится. Список читается при старте, поэтому после добавления сотрудника
бота нужно перезапустить.

Свой ID можно узнать у [@userinfobot](https://t.me/userinfobot) или отправив
сообщение этому боту — он покажет ID в ответе об отказе.

## Запуск

```
python bot.py
```

База создаётся автоматически в файле `clients.db` (путь можно задать
переменной `DB_PATH`).

Запуск на сервере (systemd или Docker) — см. [DEPLOY.md](DEPLOY.md).

## Файлы

- `bot.py` — хендлеры и запуск бота.
- `db.py` — таблица и запросы к SQLite.
- `bot.service` — юнит systemd для сервера.
- `Dockerfile`, `docker-compose.yml` — запуск в контейнере.
- `DEPLOY.md` — пошаговая инструкция по деплою.
